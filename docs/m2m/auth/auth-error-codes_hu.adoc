= Token kérés hibakódok

DCC API M2M autentikáció kommunikáció során előforduló hibakódok listája.

.Az M2M token kérés során előforduló hibakódok listája.
[cols="1,3", options="header"]
|===
| Hiba kód | Leírás

| `SSO_AUTH_FAILED`
| Érvénytelen SSO bejelentkezési adatok vagy hiányzó jogosultság!

| `SSO_INVALID_SIGNATURE`
| Az SSO aláírás érvénytelen!

| `SSO_INVALID_TIMESTAMP`
| A kapott kérés időbélyege érvénytelen!

| `DCC_AUTH_FAILED`
| Érvénytelen bejelentkezési adatok vagy hiányzó jogosultság!

| `SSO_REQUEST_ID_NOT_UNIQUE`
| A megadott kérés azonosítója már létezik!

| `SSO_ERROR`
| SSO hiba!

|===
